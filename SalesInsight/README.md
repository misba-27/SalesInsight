# SalesInsight

## Sales Data Analytics System

SalesInsight is a Python-based sales data analytics project that analyzes sales transactions to identify important business insights, performance patterns, and sales trends.

## Objective

The objective of SalesInsight is to analyze sales data using Python, NumPy, and Pandas and present meaningful results through data visualization.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- CSV

## Dataset

The dataset contains sales transaction information including:

- Order ID
- Date
- Product
- Category
- Region
- Quantity
- Unit Price

The `Sales` value is calculated using:

**Sales = Quantity × Unit Price**

## Data Processing

The project performs:

1. Dataset loading
2. Data inspection
3. Missing-value checking
4. Duplicate checking
5. Invalid-value checking
6. Date conversion
7. Sales calculation
8. Feature creation
9. Statistical analysis
10. Data visualization

## Analysis

The project calculates:

- Total Revenue
- Average Sale
- Highest Transaction
- Lowest Transaction
- Best Product
- Best Category
- Best Region
- Highest Sales Date
